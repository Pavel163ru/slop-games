## 2. Концепция (Elevator Pitch)

> Roguelite-шутер вид сверху, где игрок выбирается из затопленного зомби здания этаж за этажом. Каждая попытка — уникальная генерация уровней, врагов и лута. Прокачка между забегами позволяет зайти дальше.

**Цикл геймплея:**
Выбрать стартовый этаж → пройти через комнаты, убивая зомби → собирать оружие, аптечки, улучшения → добраться до лестницы на следующий этаж → повторить → выжить как можно дольше.

---

## 3. Геймплей

### 3.1 Основной цикл
1. **Старт забега** — выбор персонажа/бонуса за прошлый прогон (если есть)
2. **Этаж** — набор случайно сгенерированных комнат, соединённых коридорами
3. **Комнаты** — зачищаются от зомби, содержат сундуки, аптечки, оружие
4. **Босс каждые N этажей** (например, 5, 10, 15...)
5. **Конец забега** — HP = 0 или игрок добрался до финального этажа (победа)
6. **Эпилог** — экран результатов, заработанная валюта для мета-прокачки

### 3.2 Вид камеры
- Строго сверху (bird's eye view)
- Игрок видит только соседние комнаты (входя в комнату — открывается тёмная зона за стенами)
- Мини-карта в углу (раскрытая часть этажа)

### 3.3 Сложность
- С каждым этажом: больше врагов, реже аптечки, сильнее враги
- Бонусные челленджи (опционально): «только холодное оружие», «без аптечек» и т.д.

## 4. Игрок

### 4.1 Характеристики
| Параметр | Описание | Начальное значение |
|---|---|---|
| HP | Здоровье | 100 |
| Speed | Скорость передвижения | 3 px/frame |
| Damage | Базовый урон (руки) | 10 |
| Range | Дальность ближнего боя | 30 px |
| Armor | Броня (снижает входящий урон) | 0 |
| Luck | Шанс критического удара / лучшего лута | 5% |

### 4.2 Управление
| Клавиша | Действие |
|---|---|
| `WASD` / `стрелки` | Движение |
| `Мышь (прицел)` | Направление стрельбы / атаки |
| `ЛКМ` | Основная атака (оружие) |
| `ПКМ` | Бросить гранату / использовать предмет |
| `Shift` | Бег (ускорение, расход stamina) |
| `E` | Взаимодействие (открыть дверь, подобрать, сундук) |
| `R` | Перезарядка |
| `1-5` | Переключение оружия |
| `Tab` | Пауза / статистика забега |
| `I` | Инвентарь |

### 4.3 Дополнительные параметры
- **Stamina** — бег потребляет, восстанавливается стоя
- **Inventory** — 4–6 слотов для оружия + 2 слота для предметов (аптечки, гранаты, бусты)

| Тип | HP | Урон | Скорость | Особенность | Этаж появления |
|---|---|---|---|---|---|
| **Walker** (ходячий) | 30 | 5 | медленный | Базовый, тупой | 1 |
| **Runner** (бегун) | 25 | 8 | быстрый | Догоняет, но хрупкий | 2 |

| **Spitter** (плёвщик) | 35 | 7 | средний | Далёкая атака (кислота), замедляет | 5 |
| **Boomer** (взрывной) | 40 | 0 (взрыв 30) | медленный | Взрывается при смерти, AoE | 6 |
| **Tank** (босс мини) | 300 | 30 | очень медленный | Кидает обломки | 10 |
| **Necromancer** (некромант) | 60 | 10 | средний | Призывает слабых зомби | 8 |
| **Shadow** (теневой) | 40 | 15 | быстрый | Невидим пока не атакует | 12 |

### 5.2 Поведение ИИ (простое состояние)
```
IDLE → видит игрока → CHASING → в досягаемости → ATTACKING
                                    ↳ нет линии обзора → PATROL (случайное движение к последней позиции)
```

## 7. Генерация уровней

### 7.1 Алгоритм
- **Dungeon generation:** BSP-дерево или клеточный автомат (Binary Space Partitioning)
- Этаж = сетка 50×50 тайлов (размер тайла = 32×32 px)
- 8–15 комнат на этаж
- Комнаты соединены коридорами
- 1 вход + 1 выход (лестница) на каждый этаж
- Мёртвые-end коридоры → сундуки с лутом

### 7.2 Система комнат
```
┌─────────────────────────────┐
│                             │
│  [комната]----[комната]     │
│      |            |          │
│  [комната]  [коридор] [комната]
│              |                │
│         [лестница]            │
└─────────────────────────────┘
```

### 7.3 Сундуки
- **Обычный** — оружие / предмет (60%) / аптечка (40%)
- **Редкий** (золотая рамка) — улучшенное оружие / редкий предмет (100%)
- **Секретный** — за стеной, спрятан → бонусный крошечный этаж

### 7.4 Взаимодействие с окружением
- Двери (обычные — открываются, взламываются)
- Баррикады (временная защита, ломаются)
- Взрываемые бочки (урон + поджог зомби)
- Ямы / водопады (одноразовая ловушка для зомби)

## 8. Система прогрессии (между забегами)

### 8.1 Валюта
- **Кости (Bones)** — зарабатываются за каждый забег (больше = дальше прошёл)
- Тратятся в «магазине между забегами»

### 8.2 Постоянные улучшения (вкладыши / пассивки)
| Улучшение | Стоимость | Эффект |
|---|---|---|
| +10 макс. HP | 50 костей | +10 HP к каждому забегу |
| +5% скорости | 80 костей | +5% скорости |
| Слот оружия | 120 костей | +1 слот оружия (макс 3) |
| Слот предмета | 100 костей | +1 слот предмета |
| Улучшение стартового оружия | 200 костей | Пистолет → Пистолет с глушителем |
| +10% Luck | 60 костей | Лучший лут, криты |
| Дополнительный HP-буст на старте | 150 костей | Стартуешь с 130 HP |

### 8.3 Перки-преимущества перед забегом (выбирать 1 из 3)
- «Стартовая аптечка»
- «Оружие повышенного ранга»
- «+30 HP»
- «Карта этажа открыта»

### 8.4 Уровни персонажей (не персонажи, а уровень игрока)
- За каждый забег начисляется XP
- Уровень повышается → разблокирует улучшения

## 9. Визуал и стиль

### 9.1 Графика
- **Примитивная / минималистичная** — пиксель-арт или простые геометрические фигуры
- Игрок: квадрат/круг с палкой (оружие) + глаз (направление взгляда)
- Зомби: зелёные/серые фигуры с повреждениями
- Комнаты: коричневые/серые стены, тёмный пол
- Эффекты: красные пиксели (кровь), оранжевые (огонь), белые (взрыв)
- UI: минималистичный, монохромный или в стиле терминала

### 9.2 Цветовая палитра
```
Стены:        #3d3d3d, #5a5a5a
Пол:           #2a2a2a
Игрок:         #00ff88 (неон-зелёный)
Зомби:         #8b0000, #556b2f, #2f4f4f
Лут/предметы:  #ffd700 (золотой), #ff4500 (оранжевый)
HP бар:        #ff0000 → #00ff00
UI:            #cccccc на #1a1a1a
```

### 9.3 Звуки
- Хруст шагов (разные поверхности — опционально)
- Хрюканье / рычание зомби
- Выстрелы (для каждого оружия свой звук)
- Взрыв гранаты
- Звук подбора предмета
- Гулкое дыхание при низком HP (атмосфера)
- Зомби-грунт (ambient)
- Музыка: минималистичный эмбиент / тёмный электронный бит

> **Звук:** Web Audio API с генерацией простых звуков программно или бесплатные звуки.

## 10. Техническая архитектура

### 10.1 Структура проекта
```
/dead-run/
├── index.html
├── css/
│   └── style.css
├── js/
│   ├── main.js            // Точка входа, game loop
│   ├── game.js            // Конечный автомат игры (states)
│   ├── input.js           // Обработка ввода
│   ├── player.js          // Игрок
│   ├── entities/
│   │   ├── zombie.js      // Базовый зомби
│   │   ├── zombieTypes.js // Типы зомби
│   │   └── projectile.js  // Пули, гранаты
│   ├── items/
│   │   ├── weapon.js       // Система оружия
│   │   ├── consumable.js   // Аптечки, бусты
│   │   └── lootTable.js    // Таблицы лута
│   ├── level/
│   │   ├── generator.js    // BSP / генерация этажей
│   │   ├── room.js         // Комната
│   │   ├── tilemap.js      // Карта тайлов
│   │   └── fog.js          // Туман войны / видимость
│   ├── ui/
│   │   ├── hud.js          // HUD (HP, инвентарь, миникарта)
│   │   ├── menu.js         // Меню
│   │   └── popup.js        // Экраны: пауза, Game Over, Victory
│   ├── combat.js           // Система боя
│   ├── save.js             // Сохранение/загрузка (localStorage)
│   └── utils/
│       ├── math.js         // Вспомогательные функции
│       └── pathfinding.js  // Простой pathfinding для зомби
├── assets/
│   ├── sounds/             (опционально)
│   └── sprites/            (опционально)
└── README.md
```

### 10.2 Игровой цикл
```
init() → requestAnimationFrame →
  update(dt) → handleInput() → player.update() → enemies.update(dt) → combat.resolve() → projectiles.update() → checkDeath() →
  render() → ctx.clear() → level.render() → entities.render() → ui.render() →
  requestAnimationFrame ...
```

### 10.3 Состояния игры (State Machine)
```
MENU → CHARACTER_SELECT → PLAYING → PAUSED → GAME_OVER → VICTORY → UPGRADES_SHOP → ...
```

### 10.4 Сохранение (localStorage)
```js
save = {
  version: 1,
  totalBones: 0,
  bestFloor: 0,
  unlockedUpgrades: [],
  playerLevel: 1,
  totalXP: 0
}
```

### 10.5 Оптимизация производительности
- Канвас фиксированного разрешения (например, 800×600, масштабируется через CSS)
- Object pooling для пуль и частиц
- Отрисовка только видимой области
- Зомби: простой pathfinding (BFS по сетке, кеширование пути каждые N кадров)

## 11. MVP (Минимально Играбельная Версия) — Релиз 1.0

### Что ДОЛЖНО быть в MVP:
- [ ] Меню (Старт, Управление, Магазин между забегами)

- [ ] Система HP персонажа и врагов

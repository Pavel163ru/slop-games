# Dungeon Match

Match-3 RPG в тёмном подземелье (как Puzzle Quest). Vanilla JS + Canvas, без зависимостей.

## Запуск

Браузер блокирует ES-модули при открытии через `file://`, нужен локальный сервер:

- Windows: двойной клик по `run.bat`
- вручную: `python server.py` → открыть http://127.0.0.1:8000/index.html

## Как играть

1. Меню → Новая игра (Обычная / ☠ Хардкор) → карта подземелья.
2. На карте 10 рядов с ветвлениями: выбирай путь, ★ элитники дают ×2 награды, 🎁 сокровищница даёт золото.
3. Бой: свап фишек клик-клик. Меч — урон, щит — броня, мана — заряд, зелье — лечение, золото — лут.
4. Матч-4 = ×2, матч-5 = ×3 + доп. ход, на матче-5 шанс крита ×2. Мечи-4+ вешают кровотечение, щиты-4+ — слабость.
5. Красная цифра — следующий удар врага. После твоего хода враг бьёт в ответ.
6. Победа: золото + опыт → выбор бонуса → лавка → следующий ряд. Убей Лича.
7. После победы — NG+: враги сильнее, награды выше. Достижения — в меню.

Горячие точки: M — звук, 💡 — подсказка хода, 🧪💣🔀 — расходники в бою.

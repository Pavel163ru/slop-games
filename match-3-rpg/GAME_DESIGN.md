# Dungeon Match — Механика игры (v1)

> Жанр: Match-3 RPG (как Puzzle Quest). Сеттинг: тёмное подземелье.
> Стек: Vanilla JS + Canvas, без сборщика и ассетов.

## 1. Core Loop

1. Игрок заходит в комнату подземелья → начинается пошаговый бой.
2. Ход игрока: свап двух соседних фишек **клик-клик** → матч даёт ресурсы/урон.
3. Ответ врага: фиксированный урон (в v1 — без ИИ).
4. Победа → золото + XP → (level-up / магазин) → следующая комната.
5. Поражение → Game Over → рестарт с сейва. Победа над боссом → Victory.

## 2. Игровое поле

- Размер: **8x8**, отрисовка на **Canvas** (клетка 64px → 512x512, с учётом `devicePixelRatio`).
- Ввод: клик по клетке → подсветка → клик по ортогональному соседу (Манхэттен = 1).
- Невалидный свап (не сосед / не дал матча) — откат + звук ошибки.
- Генерация поля: без стартовых троек + гарантия `hasPossibleMove()`, иначе пересоздание.
- Гравитация: фишки падают вниз, сверху спавнятся новые по весам.
- **Каскады:** после падения снова ищем матчи, повторяем до пустого результата.

### Веса спавна (v0.1)

| Тип    | Вес | Шанс |
|--------|-----|------|
| Меч    | 22  | 22%  |
| Щит    | 20  | 20%  |
| Мана   | 22  | 22%  |
| Золото | 24  | 24%  |
| Зелье  | 12  | 12% (редкое) |

## 3. Типы фишек и эффекты

| Фишка | ID      | Эффект матча-3 (база) | Цвет спрайта |
|-------|---------|------------------------|--------------|
| Меч   | `sword` | 3 урона врагу          | красный      |
| Щит   | `shield`| +3 брони               | серо-голубой |
| Мана  | `mana`  | +3 маны                | синий        |
| Зелье | `potion`| +3 HP (не выше maxHP)  | зелёный      |
| Золото| `gold`  | +3 золота (лут)        | золотой      |

Эффект за ход = сумма эффектов всех групп матчей с учётом множителя.

### Множители длины

| Длина | Множитель | Бонус        |
|-------|-----------|--------------|
| 3     | x1        | —            |
| 4     | x2        | **+ extra-ход** (враг пропускает атаку) |
| 5+    | x3        | **+ extra-ход** |

Пересечения (Г/Т-образные): считаются как две независимые группы, каждая со своим множителем.

## 4. Машина состояний боя

```
playerTurn → resolve → [extraTurn ? playerTurn : enemyTurn] → checkEnd → ...
```

1. **playerTurn** — ожидание свапа или каста заклинания.
2. **resolve** — подсветка матчей (200мс) → применение эффектов → падение/спавн → каскады.
3. **enemyTurn** — пауза 600мс → урон врага минус броня → броня **сгорает полностью**.
4. **checkEnd** — `enemy.hp <= 0` → победа; `player.hp <= 0` → поражение.

Каст заклинания тратит ход (после него ходит враг), кроме случая добивания.

## 5. Игрок

| Параметр | Старт | Описание |
|----------|-------|----------|
| HP       | 50    | Текущее / maxHP |
| maxHP    | 50    | Растёт за level-up и магазин |
| Armor    | 0     | Поглощает урон, сгорает после удара врага |
| Mana     | 0 | Ресурс заклинаний, старт каждого боя с 0 (решение 05.09.2026) |
| ATK      | 0     | +1 к урону мечей за матч (прокачка) |
| XP / Level | 1   | XP за победы, level-up → +1 к статам на выбор |

> Стартовая мана: 0. Фаербол/лечение/щит доступны только после набора маны с поля.

Формула урона мечей: `(3 + ATK) × множитель × кол-во групп`.

## 6. Враги и подземелье (v2: ветки, элита, NG+)

10 рядов; ветки на рядах 3 (скелет ★), 6 (слайм/культист), 9 (страж ★);
ряд 5 — сокровищница +90 зол. без боя. Элита ★: HP ×1.5, +2 урон, награды ×2.
NG+: за цикл HP ×1.35, урон ×1.25, награды ×1.2. Хардкор: +15% HP врагов, смерть = вайп сейва.

| # | Враг | HP | Урон | Особенность |

| 2 | Летучая мышь | 40 | 7–9 | — | 40 | 30 |

## 8. Прокачка и экономика (между боями)

- **XP:** порог level-up: `100 × level`. Суммарно за 10 боёв 1000 XP (5-й уровень к финалу).
- **Level-up:** выбор +1: maxHP (+10 и лечение 10), ATK (+1), стартовая мана (+2) — оверлей на Canvas после боя, очередь при нескольких уровнях.
- **Магазин** (с карты + возврат после каждого боя): зелье в бой 30g (+25 HP в бою, макс 3), лечение 25g (HP полностью), +10 maxHP 100g.
- **Золото:** с матчей `gold` + награда за победу (25–150 по силе врага).
- **HP переносится между боями.** Поражение мягкое: возврат на карту с полным HP, узел сохранён.

## 9. Экраны / структура v1 (весь UI — в Canvas, DOM-модалок нет)

Принцип (решение 05.09.2026): **никаких HTML-модалок.** Все экраны, HUD,
кнопки заклинаний, level-up, магазин, победа/поражение рисуются на Canvas
и кликаются координатами. `index.html` содержит только `<canvas>` + базовые стили.

1. **Меню:** Новая игра / Продолжить (если сейв) / Как играть.
2. **Карта подземелья:** линейная цепочка из 10 узлов (решение 05.09.2026), текущий подсвечен, превью врага, кнопки «В бой» / «Лавка».
3. **Бой:** Canvas + HUD игрока/врага + панель заклинаний + лог боя.
4. **Модалки (Canvas-оверлеи, не DOM):** level-up (выбор стата), магазин, победа/поражение.

### Прототип v0.1 (первый шаг)

Только бой: поле + Крыса + HP/мана. Без меню, карты, магазина, сейвов.
Критерий: свапы, каскады, extra-ход, ответ врага, победа/поражение с кнопкой «Заново».

## 10. Техническая архитектура

```
index.html          — каркас: canvas#board, HUD, спеллы, лог
style.css           — тёмная тема подземелья
js/
  main.js           — init, связывание модулей
  board.js          — поле: генерация, свап, findMatches, collapse, каскады (не знает про бой)
  battle.js         — автомат ходов, маппинг матчей → эффекты
  player.js         — HP/maxHP/armor/mana/ATK/gold/level/XP/startMana/potions
  enemies.js        — таблица 10 врагов + pierce/regen/armor/powerEvery
  spells.js         — 5 заклинаний с unlock-уровнями
  shop.js           — товары лавки, цены, условия (решение: лавка после каждого боя + с карты)
  audio.js          — WebAudio осцилляторы (swap/match/hit/heal/win/lose), без файлов
  save.js           — localStorage (v1, не прототип)
  ui.js             — ВЕСЬ рендер на Canvas: поле, спрайты, HUD игрока/врага,
                      панель заклинаний, лог (последние строки), оверлеи победы/
                      поражения/level-up/магазина. Клик-координаты кнопок — в ui.js.
```

- `board.js` возвращает `[{type, len, cells}]`, `battle.js` решает что с этим делать.
- Спрайты рисуются кодом: меч (треугольник+рукоять), щит (пятиугольник), мана (ромб), зелье (круг+горлышко), монета (круг).
- Анимации v0.1: подсветка матча, падение 150мс (lerp), тряска при уроне (CSS-класс).

## 11. Звук (WebAudio, без файлов)

`swap, match, hit, heal, shield, fireball, win, lose, error, click` + кнопка mute.

## 12. Сейв (v1)

`localStorage['dungeon-match-save']`: `{level, xp, stats, gold, dungeonNode, inventory}`.
Автосейв после каждого боя и покупки.

## v2 — Контент и режимы ✅ (05.09.2026)

- [x] Ветвящаяся карта: 10 рядов, 3 ветки (элита ★ ×2 награды / альтернативный путь), сокровищница +90 зол.
- [x] Лавка доступна с карты всегда (= чекпоинты) + 5 случайных событий между боями (35%)
- [x] Новые заклинания: каменная кожа (ур.2), берсерк (ур.4), цепная молния (ур.6, NG+)
- [x] Расходники в бою: бомба 💣 (25 урона, тратит ход), перемешка 🔀 (бесплатная)
- [x] NG+: враги +35% HP/+25% урона за цикл, награды +20%; вместо боссов 2-го акта
- [x] 8 достижений в localStorage + тосты 🏆
- [x] Сложности: Обычная / Хардкор (+15% HP врагов, смерть = вайп сейва)

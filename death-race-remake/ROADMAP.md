## 1. Этап A — Контент кампании ✅ ВЫПОЛНЕН

**Цель:** выйти за пределы одного города. Была одна карта, «ВИЗИТ N» менял только число врагов.

**Реализовано 06.09.2026:**
- A1 ✅ Реестр `CITIES` из 8 городов в `config.js` (флаги 2/2/3/3/3/4/4/4, `timerK`, `diffK`, штаты)
- A2 ✅ Прогресс: `winLevel()` ведёт по городам 1→8, сохранение города в `localStorage`, продолжение кампании после перезапуска, game over сбрасывает. **Решение от 06.09: один круг по городам** — финал сразу после 8-го города (двойной визит из спеки §3.3 не используем)
- A3 ✅ `CITY_THEMES`: палитра асфальта/тротуаров/крыш/разметки, плотность застройки и кондиционеры по городам, вертолётные площадки только в «высотных» городах
- A4 ✅ `effDiff(diff, city)`: вертолёты 1→4, шахты 2→4, темп стрельбы шахт ×0.97^к, паника/скорость вертолётов растут; суммируется с надбавкой визитов
- A5 ✅ Финал кампании: экран «КАМПАНИЯ ПРОЙДЕНА» с титрами после 16 уровней; в HUD/брифинге показываются текущий город, круг, правильное число флагов и таймер

Проверено headless-прогоном (vm, 16 побед подряд → финал, сейвы, сбросы).

**Дополнительно (по замечанию об оригинале):** город обнесён бетонным забором по периметру
(`CityMap.fence`, статичный слой + коллизии для машины/гремлинов/пуль/ракет). Северная стена
имеет проезд с воротами: закрытый шлагбаум с красными огнями, пока не собраны все флаги;
после сбора — подсветка проезда, зелёные огни, анимированные стрелки и выезд = победа.
На миникарте добавлен контур забора.

**Экран карты США (как в оригинале):** новый стейт `citymap` (`render/citymap.js`) — перед
каждым городом показывается стилизованная карта США с маршрутом: пройденные города —
зелёные точки, текущий — пульсирующий красный маркер с жёлтым кольцом, оставшиеся — серые.
Пройденная часть маршрута зелёная, впереди — жёлтый пунктир. Координаты городов — реальные
(долгота/широта, `geo` в `CITIES`), проекция равнопромежуточная. Поток: меню/победа →
карта → брифинг → магазин → заезд.

# Dungeon Match

Офлайн match-3 RPG о герое, который сражается с обитателями подземелья и пробивается к Личу. Игра написана на обычных HTML, CSS и JavaScript; поле и интерфейс рисуются на Canvas, графика хранится в локальных SVG.

## Запуск

Открой `index.html` в браузере. Можно запускать прямо с диска: сервер, установка пакетов и интернет не нужны.

- **Новая игра** — обычный забег с сохранением между боями.
- **Хардкор** — один забег; поражение завершает его.
- **Продолжить** — восстановить последнее автосохранение.
- **Демо первого боя** — отдельный быстрый бой с крысой без кампании; страница `demo.html`.
- **Спрайты** — каталог локальной графики на странице `sprite-viewer.html`.

## Полная игра

Кампания проходит через 10 рядов: от крысы и летучих мышей до Лича. В ней есть выбор элитных маршрутов, альтернативный противник на шестом ряду, сокровищница, случайные события и NG+ с усиленными врагами.

- Поле 8 × 8: обмен соседних фишек, пять ресурсов, каскады, подсказка и бесплатное перемешивание при отсутствии ходов.
- Матчи мечей атакуют, щитов создают броню, мана питает заклинания, зелья лечат, золото пополняет кошелёк. Матчи-4+ дают дополнительный ход.
- Враги отличаются бронёй, пробивающими атаками, регенерацией, проклятиями, призывом прислужников и усиленными ударами босса. Следующая атака врага видна заранее.
- Восемь заклинаний открываются по мере роста уровня; доступны зелья, бомбы и руны перемешивания.
- За бои даются XP и золото. При повышении уровня выбери одно из улучшений здоровья, силы мечей или стартовой маны.
- Лавка доступна с карты, а после сокровищницы открывается автоматически. Между боями могут появиться алтари, торговец, ловушки, тайники и колодец.
- Прогресс забега, достижения и настройка звука сохраняются локально. Обычное поражение возвращает героя на карту с полным здоровьем; расходники и золото остаются потраченными.
- Интерфейс подстраивается под размер экрана; в компактном режиме заклинания и предметы переезжают в панель рядом с полем.

## Демо первого боя

`demo.html` оставлено отдельной страницей для быстрого тестирования боя с крысой. Здесь доступны поле 8 × 8, стартовые три заклинания, зелье, подсказка, сброс и победа/поражение без карты, прокачки или сохранения кампании. Для небольших экранов магия автоматически переносится в панель слева.

## Просмотрщик спрайтов

В `sprite-viewer.html` доступны поиск по имени и ключевым словам, фильтры по категориям, три варианта фона и регулировка размера превью. В каталоге 27 спрайтов:

- 5 фишек: меч, щит, мана, зелье и золото;
- герой и 10 врагов подземелья;
- бомба, перемешка и сундук;
- 8 заклинаний.

Все ресурсы — самостоятельные SVG размером 128 × 128 с прозрачным фоном. Поле и HUD полной игры и демо рисуются на Canvas; SVG загружаются с диска и отображаются через `drawImage`.

## Подключение спрайтов в Canvas

На HTML-странице игры подключи обычный скрипт после canvas:

```html
<canvas id="game" width="512" height="760"></canvas>
<script src="js/sprites.js"></script>
<script>
  const canvas = document.getElementById("game");
  const context = canvas.getContext("2d");

  DungeonSprites.load("token-sword").then(function (image) {
    context.drawImage(image, 0, 0, 64, 64);
  });
</script>
```

Доступные методы реестра:

- `DungeonSprites.list` — описания всех ресурсов;
- `DungeonSprites.get("enemy-lich")` — описание одного спрайта или `null`;
- `DungeonSprites.load("enemy-lich")` — Promise с загруженным `HTMLImageElement`;
- `DungeonSprites.preload()` — Promise, который разрешается после загрузки изображений; можно передать массив ID.

Пути ресурсов заданы относительно HTML-страницы: запускай страницу из корня проекта, как `index.html`. Реестр не использует `fetch`, ES-модули, CDN или другие сетевые запросы, поэтому подходит для открытия через `file://`.

```text

GAME_DESIGN.md             описание правил и структуры игры
README.md                  этот файл
assets/sprites/            отдельные SVG-спрайты
css/full-game.css          стили полной игры

js/game.js                 кампания, бои, интерфейс, сохранения и события
```

## Добавление спрайта

1. Добавь SVG-файл в `assets/sprites/`. Для единообразного отображения используй `viewBox="0 0 128 128"`.
2. Добавь описание спрайта в массив `sprites` внутри `js/sprites.js`: ID, имя, категорию, имя файла, описание и ключевые слова.
3. Перезагрузи `sprite-viewer.html` — отдельная страница просмотра обновится автоматически.

## Дизайн игры

Правила, таблицы врагов, экономика и техническая структура описаны в [`GAME_DESIGN.md`](GAME_DESIGN.md). `index.html` запускает полную кампанию; `demo.html` оставлена как быстрая площадка для проверки первого боя.

## Проверка

Если установлен Node.js, запусти `node tests/smoke.cjs`: тест проверяет создание кампании, переход с карты в бой, автосохранение, допустимый ход и 100 случайных игровых полей.
